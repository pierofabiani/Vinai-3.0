# Modelli delle malattie

Python. Tre gradini:

1. **Modelli pubblicati** (stagione 2027): peronospora, oidio, botrite, black rot, fenologia. Scelta e soglie da concordare con l'agronomo; parametri presi dagli articoli originali, citati nel codice.
2. **Validazione e calibrazione** sulle osservazioni di campo confermate.
3. **AI** quando i dati validati bastano: modello di previsione spiegabile, lettore dei bollettini regionali, controllo qualità dei sensori.

Ogni allarme deve poter dire il perché.
