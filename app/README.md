# App

PWA installabile per chi usa le centraline: Oggi, Mappa, Vigneto, Malattie, Osservazioni, Trattamenti, Notifiche, Azienda. TypeScript, React, MapLibre.

Si parte dal design: prima le schermate principali in due direzioni visive, poi il codice. Direzione: strumentazione di precisione per la vigna, scura come base, con modalità campo chiara ad alto contrasto. Dettagli nel piano di progetto (traccia C).
